# Flutter Widgets Everything Is A Widget

This Flutter example demonstrates the core concept that "everything is a widget." It showcases how an entire application, its layout, text, buttons, and even icons are all composed of various widgets nested within each other. The app features a simple counter that increments when a button is pressed, illustrating both stateless and stateful widgets in action.

## Language

`dart`

## How to Run

1. Ensure you have the Flutter SDK installed and configured.
2. Save the code as `main.dart` inside a new Flutter project (e.g., `flutter create my_widgets_app` then replace `lib/main.dart`).
3. Run the application from your terminal: `flutter run`
